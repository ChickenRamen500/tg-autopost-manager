## 📌 О проекте

**TG Media Queue Bot** — это приватный Telegram-бот с веб-интерфейсом для автоматизации сбора, обработки, модерации и отложенной публикации медиаконтента (изображения, видео, GIF) в 5–6 целевых Telegram-каналов.

Система развивает идеи репозитория [gbooru_tg](https://github.com/ChickenRamen500/gbooru_tg), добавляя универсальную очередь задач, веб-управление, Chrome-расширение и поддержку Local Bot API Server для обхода лимитов на размер файлов.

## ⚡ Ключевые особенности

- **Двойной интерфейс управления**: 
  - *Telegram (ЛС)* — для быстрой загрузки, модерации и управления подписками.
  - *Веб-интерфейс* — для детального управления очередями, файлами, кропом видео и маршрутизацией.
- **Очередь как основной механизм**: Все посты по умолчанию попадают в очередь и публикуются по расписанию (APScheduler). Немедленная отправка — исключение.
- **Local Bot API Server**: Снимает ограничения облачного API (загрузка до 2 ГБ, безлимитное скачивание через `getFile`).
- **Множественные источники**: Прямая загрузка из Telegram, локальные папки, Chrome-расширение, автопарсинг (Gelbooru, Danbooru, X.com, Pikabu, Pixiv).
- **Интеллектуальная обработка**: 
  - Гибкая маршрутизация по правилам (regex/точное совпадение).
  - Конвейер обработки подписей (фильтрация, добавление случайных фраз).
  - Двухуровневый поиск дубликатов (точный по `file_unique_id`/`source_id` и визуальный по `pHash`).
  - Точечный кроп видео (удаление водяных знаков через `ffmpeg -preset ultrafast`).
- **Оптимизация под слабое железо**: Рассчитан на работу на AMD Athlon X4 / 8 ГБ RAM (строгие лимиты Docker, асинхронность, легковесный фронтенд).

## 🛠 Технологический стек

| Компонент | Технологии |
|-----------|------------|
| **Backend** | Python 3.11+, FastAPI, aiogram 3.x (через Local Bot API Server) |
| **База данных** | SQLite (`aiosqlite`) |
| **Планировщик** | APScheduler (`AsyncIOScheduler`) |
| **Обработка медиа** | `ffmpeg` (кроп, транскодирование), `Pillow` + `imagehash` (pHash) |
| **Парсинг** | `aiohttp`, `yt-dlp` (для X.com и сложных видео), опционально `pixivy` |
| **Frontend** | Jinja2 + Bootstrap 5 + Vanilla JavaScript (без тяжелых фреймворков) |
| **Инфраструктура** | Docker Compose (контейнеры `bot` и `local-bot-api`) |
| **Расширение** | Chrome Extension (Manifest V3) |
