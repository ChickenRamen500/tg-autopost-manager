## 📌 О проекте

**TG Media Queue Bot** — это приватный Telegram-бот с веб-интерфейсом для автоматизации сбора, обработки, модерации и отложенной публикации медиаконтента (изображения, видео, GIF) в 5–6 целевых Telegram-каналов.

Система развивает идеи репозитория [gbooru_tg](https://github.com/ChickenRamen500/gbooru_tg), добавляя универсальную очередь задач, веб-управление, Chrome-расширение и поддержку Local Bot API Server для обхода лимитов на размер файлов.

## ⚡ Ключевые особенности

- **Двойной интерфейс управления**: 
  - *Telegram (ЛС)* — для быстрой загрузки, модерации и управления подписками.
  - *Веб-интерфейс* — для детального управления очередями, файлами, кропом видео и маршрутизацией.
- **Очередь как основной механизм**: Все посты по умолчанию попадают в очередь и публикуются по расписанию (APScheduler). Немедленная отправка — исключение.
- **Local Bot API Server**: Снимает ограничения облачного API (загрузка до 2 ГБ, безлимитное скачивание через `getFile`).
- **Множественные источники**: Прямая загрузка из Telegram, локальные папки, Chrome-расширение, автопарсинг (Gelbooru, Danbooru, X.com, Pikabu, Pixiv).
- **Интеллектуальная обработка**: 
  - Гибкая маршрутизация по правилам (regex/точное совпадение). ✅
  - Конвейер обработки подписей (фильтрация, добавление случайных фраз). ⬜ Фаза 5
  - Двухуровневый поиск дубликатов (точный по `file_unique_id`/`source_id` ✅ и визуальный по `pHash` ✅ Фаза 3).
  - Точечный кроп видео (удаление водяных знаков через `ffmpeg -preset ultrafast`). ⬜ Фаза 5
- **Оптимизация под слабое железо**: Рассчитан на работу на AMD Athlon X4 / 8 ГБ RAM (строгие лимиты Docker, асинхронность, легковесный фронтенд).
- **Автодеплой и операционные уведомления** (вне ТЗ v5, см. [`DOCS/AUTO_DEPLOY.md`](./DOCS/AUTO_DEPLOY.md)): push в `main` → GitHub Actions → webhook `/webhook/deploy` → watcher на хосте пересобирает контейнеры; после рестарта админ получает «🚀 Бот перезапущен после автодеплоя», ERROR/CRITICAL из лога контейнера шлются дайджестом в ЛС/служебный канал. ✅
- **Уведомление о запуске** (v0.4.63): через 60 сек после старта бот шлёт в служебный канал ДВА сообщения — (1) сводку «🟢 Бот запущен, очереди загружены» со списком очередей и кол-вом постов по статусам, (2) описание последнего коммита GitHub (что сделано в сборке). Настраивается через `STARTUP_NOTIFY_DELAY_SECONDS` / `GITHUB_REPO` / `GITHUB_BRANCH`. ✅

## 🛠 Технологический стек

| Компонент | Технологии |
|-----------|------------|
| **Backend** | Python 3.11+, FastAPI, aiogram 3.x (через Local Bot API Server) |
| **База данных** | SQLite (`aiosqlite`) |
| **Планировщик** | APScheduler (`AsyncIOScheduler`) |
| **Обработка медиа** | `ffmpeg` (кроп — ⬜ Фаза 5), `Pillow` + `imagehash` (pHash — ✅ Фаза 3) |
| **Парсинг** | `aiohttp`, `yt-dlp` (для X.com и сложных видео), опционально `pixivy` (устанавливается отдельно: `pip install pixivy`; в базовом образе отсутствует на PyPI — см. requirements.txt) |
| **Frontend** | Jinja2 + Bootstrap 5 (✅ веб-интерфейс реализован: dashboard/queues/inbox/sent/posts/routing/channels/local_files) |
| **Инфраструктура** | Docker Compose (контейнеры `bot` и `local-bot-api`), GitHub Actions auto-deploy (Tailscale + webhook, вне ТЗ — см. `DOCS/AUTO_DEPLOY.md`) |
| **Расширение** | Chrome Extension (Manifest V3) (✅ Фаза 4: quick_add через REST API) |

## 🚀 Быстрый старт

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/ChickenRamen500/tg-autopost-manager.git
   cd tg-autopost-manager
   ```

2. **Настройте переменные окружения**:
   Создайте файл `.env` на основе `.env.example`. Вам понадобятся:
   - `BOT_TOKEN` (от @BotFather)
   - `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` (с [my.telegram.org](https://my.telegram.org))
   - `SECRET_TOKEN` (для защиты API и Chrome-расширения)

3. **Запустите через Docker Compose**:
   ```bash
   docker compose up -d
   ```
   *При первом запуске убедитесь, что бот "разлогинен" от облачного API (см. раздел "Миграция" в полном ТЗ).*

4. **Доступ к интерфейсам**:
   - **Веб-интерфейс**: `http://<локальный-IP>:8000` (HTTP Basic Auth)
   - **Telegram-бот**: начните диалог с `/start` (требуется предварительное добавление вашего `tg_id` в БД как `admin`).

## ⚠️ Ограничения и безопасность

- **Приватность**: Доступ только для авторизованных пользователей (до 10 человек).
- **Локальность**: Веб-интерфейс не проброшен во внешнюю сеть, доступен только из локальной сети.
- **Лимиты обработки**: Кроп видео на слабом CPU ограничен файлами до 50 МБ (используется `preset ultrafast`). Большие файлы отправляются как есть благодаря Local Bot API Server.
